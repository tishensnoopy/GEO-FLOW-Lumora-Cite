## 1. 系统概述

本平台由**两个后台**组成，通过 SSO（单点登录）打通，一次登录即可访问两个系统：

| 系统 | 网址 | 用途 |
|------|------|------|
| **监测系统 Dashboard** | `https://monitor.zkeeeai.com` | 查看收录数据、AI 采信统计、导出报告 |
| **GEOFlow 内容管理后台** | `https://zkeeeai.com/geo_admin` | 创作文章、分发内容到多渠道、管理网站 |

### 两个后台的关系

```
用户访问监测系统 → SSO 跳转 GEOFlow 登录 → 登录成功后返回监测系统
                    ↓
         同时也可直接访问 GEOFlow 后台（免再次登录）
```

- **监测系统**是日常入口：看数据、导出报告
- **GEOFlow 后台**是内容入口：写文章、发内容
- 两个系统**共享同一套账号**，登录一次即可互通

## 2. 账号与登录

### 2.1 默认管理员账号

| 项目 | 值 |
|------|-----|
| 用户名 | `admin` |
| 密码 | `Admin@2026` |
| 权限 | 超级管理员（两个系统通用） |

> ⚠️ **安全提醒**：首次登录后请尽快修改密码（见 3.6 节）。

### 2.2 登录监测系统

1. 打开浏览器，访问：**`https://monitor.zkeeeai.com`**
2. 页面显示登录入口，点击 **「SSO 登录」** 按钮
3. 浏览器自动跳转到 GEOFlow 登录页
4. 输入用户名 `admin` 和密码 `Admin@2026`
5. 登录成功后，自动跳回监测系统 Dashboard

### 2.3 登录 GEOFlow 内容管理后台

1. 打开浏览器，访问：**`https://zkeeeai.com/geo_admin`**
2. 输入用户名 `admin` 和密码 `Admin@2026`
3. 登录成功后，进入 GEOFlow 管理后台

> 💡 如果你已经登录了监测系统，再访问 GEOFlow 后台时会**自动登录**，无需再输密码。

### 2.4 退出登录

- **监测系统**：点击右上角的 **「退出登录」** 按钮
- **GEOFlow 后台**：点击右上角头像 → 退出登录
- 退出一个系统后，另一个系统也需要重新登录

## 3. 监测系统 Dashboard

### 3.1 首页 — 数据看板

登录后进入首页，展示以下内容：

#### 四张统计卡片（顶部）
| 卡片 | 含义 |
|------|------|
| 分发总数 | 已分发到各渠道的内容总数 |
| 收录总数 | 被搜索引擎收录的内容数量 |
| AI 采信数 | 被 AI 模型引用的内容数量 |
| 采信率 | AI 采信数 / 收录总数 × 100% |

#### 五张图表
| 图表 | 类型 | 含义 |
|------|------|------|
| 多引擎收录趋势 | 折线图 | 各搜索引擎收录数量随时间的变化 |
| AI 采信分布 | 饼图 | 不同 AI 模型的引用占比 |
| 引擎收录对比 | 柱状图 | 各搜索引擎收录量横向对比 |
| 来源分布 | 环形图 | 内容来源渠道的分布 |
| 采信趋势 | 折线图 | AI 采信数量随时间的变化 |

#### 导出报告
- 点击右上角 **「导出报告」** 按钮
- 选择导出格式（PDF 或 Excel）
- 系统会在后台生成报告，生成完成后可下载

### 3.2 文章列表

顶部菜单点击 **「文章列表」**：
- 查看所有已分发的文章
- 点击文章可查看详情
- 显示每篇文章的收录状态和 AI 采信状态

### 3.3 分发记录

顶部菜单点击 **「分发记录」**：
- 查看内容分发到各渠道的记录
- 包含：分发时间、目标 URL、收录状态、采信状态
- 支持按客户筛选

### 3.4 导出报告

顶部菜单点击 **「导出报告」**：
- 查看历史导出任务列表
- 显示：导出类型、文件大小、状态、创建时间
- 点击 **「下载」** 获取已生成的报告

#### 导出报告步骤：
1. 在首页或导出报告页点击 **「导出报告」**
2. 选择格式：
   - **PDF 报告**：含图表和统计，适合汇报展示
   - **Excel 报告**：4 个工作表（概览/收录明细/采信明细/统计），适合数据分析
3. 点击确认，系统开始生成
4. 生成完成后（约 1-2 分钟），在导出报告列表点击下载

### 3.5 审计日志（仅管理员）

顶部菜单点击 **「审计日志」**（仅管理员可见）：
- 查看管理员操作记录
- 包含：操作类型、操作人、操作时间、详情
- 支持按操作类型筛选

### 3.6 系统设置

顶部菜单点击 **「系统设置」**：
- 查看/修改系统配置
- 配置 AI 模型 API Key（用于 AI 采信检测）
- 查看数据库连接状态

#### 修改密码
1. 进入系统设置
2. 找到「修改密码」区域
3. 输入旧密码 → 新密码 → 确认新密码
4. 点击保存

> 密码要求：至少 8 位，包含大小写字母和数字。

## 4. GEOFlow 内容管理后台

### 4.1 访问方式

直接访问：**`https://zkeeeai.com/geo_admin`**

> 如果已登录监测系统，会自动登录，无需再输密码。

### 4.2 主要功能

GEOFlow 后台是内容管理的核心，主要功能包括：

| 功能模块 | 用途 |
|----------|------|
| 文章管理 | 创作、编辑、发布文章 |
| 内容分发 | 将文章分发到多渠道（官网、自媒体、第三方平台） |
| 分发渠道管理 | 配置分发目标渠道 |
| 网站管理 | 管理官网内容和主题 |
| 用户管理 | 管理后台用户（仅超级管理员） |
| 系统设置 | 配置系统参数 |

### 4.3 创建文章

1. 左侧菜单 → 文章管理 → 新建文章
2. 填写文章信息：
   - 标题、正文、摘要
   - 关键词（用于 SEO/GEO 优化）
   - SEO 设置（meta description、slug 等）
3. 点击保存草稿 或 直接发布

### 4.4 分发内容

1. 在文章列表中，选择要分发的文章
2. 点击 **「分发」**
3. 选择目标渠道（可多选）：
   - 官网（zkeeeai.com）
   - 自媒体平台
   - 第三方平台
4. 点击确认分发
5. 分发完成后，文章会出现在监测系统的「分发记录」中
6. 监测系统会自动开始检测收录状态和 AI 采信情况

### 4.5 查看监测系统入口

GEOFlow 官网顶部菜单有 **「监测系统」** 入口，点击可直接跳转到监测系统 Dashboard。

## 5. 日常操作流程

### 5.1 每日工作流

```
1. 登录监测系统 Dashboard
   → 查看首页数据看板，了解整体收录和采信情况

2. 如需发布新内容
   → 访问 GEOFlow 后台 → 创建文章 → 分发到渠道

3. 分发后
   → 回到监测系统 → 查看分发记录，确认新内容已录入

4. 需要汇报时
   → 导出 PDF/Excel 报告
```

### 5.2 每周工作流

```
1. 导出本周报告（PDF 格式）
   → 首页 → 导出报告 → 选择 PDF → 下载

2. 分析数据趋势
   → 查看多引擎收录趋势图
   → 查看 AI 采信分布饼图
   → 对比上周数据

3. 检查异常
   → 查看是否有未收录的内容
   → 查看是否有收录但未被 AI 采信的内容
   → 针对性优化内容策略
```

### 5.3 添加新客户

如需为新客户创建独立账号：

1. 登录监测系统（需管理员权限）
2. 目前客户端账号管理通过 API 进行，联系技术人员操作
3. 新客户将获得独立的 client_id 和登录凭据
4. 客户登录后只能看到自己的数据

## 6. 常见问题

### Q1：忘记密码怎么办？

**GEOFlow 后台密码**：联系系统管理员重置，或通过服务器执行：
```bash
docker exec geoflow-postgres-prod psql -U geo_user -d geo_flow -c "UPDATE public.admins SET password='<新哈希>' WHERE username='admin';"
```

**监测系统密码**：联系系统管理员重置。

### Q2：SSO 登录跳转失败？

可能原因及解决：
1. **GEOFlow 服务未运行**：检查 `https://zkeeeai.com` 是否可访问
2. **浏览器缓存**：清除浏览器缓存或使用无痕模式
3. **Cookie 被禁用**：确保浏览器允许第三方 Cookie

### Q3：数据看板没有数据？

可能原因：
1. **还没有分发内容**：先在 GEOFlow 后台分发文章
2. **检测任务未执行**：收录检测是定时任务，可能需要等待
3. **API Key 未配置**：AI 采信检测需要配置 AI 模型 API Key（系统设置中配置）

### Q4：导出报告下载失败？

1. 检查导出报告列表中的状态是否为「已完成」
2. 如果状态为「失败」，重新尝试导出
3. 如果反复失败，联系技术人员检查 Playwright/Chromium 是否正常运行

### Q5：两个系统的密码是一样的吗？

**可以设置为一样**，但它们是**独立的密码系统**：
- GEOFlow 后台密码存储在 `public.admins` 表
- 监测系统密码存储在 `monitor.clients` 表
- 修改一个不会影响另一个

### Q6：如何访问 GEOFlow 官网前台？

访问：**`https://zkeeeai.com`**
这是面向公众的网站，展示已发布的内容。

### Q7：手机可以访问吗？

- **监测系统**：支持手机浏览器访问，但建议在电脑上使用以获得最佳体验
- **GEOFlow 后台**：建议在电脑上使用
